## How to setup
Go to shortcut.html and set your url to look like the following, replace the index.html location with your own and sus228000 with your username.
> file:///C:/Users/Admin/Downloads/scum/index.html?username=sus228000&followMode

![Showcase.](/showcases/shortcut.png)

## OBS Studio
Create a new browser source and paste in the path to your shortcut.html file in this format 
> file:///C:/Users/Admin/Downloads/scum/shortcut.html
- DO NOT SELECT LOCAL FILE

![Showcase.](/showcases/obs.png)

## Customization
Go to script.js and replace sub goal or follow goal with any tex of your liking
